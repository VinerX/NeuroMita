# NeuroMita 0.1 Alpha

NeuroMita — фанатский мод-проект, в котором можно общаться с Митами, управляемыми языковыми моделями, и видеть их реакции в Unity-сцене. Текущая версия — самостоятельный Unity-билд: для запуска не нужна установленная MiSide, в релизе есть всё необходимое.

[Скачать](https://github.com/VinerX/NeuroMita/releases) · [Discord](https://discord.gg/Tu5MPFxM4P) · [Настроить модель](docs/MODELS.md) · [Решить проблему](docs/TROUBLESHOOTING.md)

> **Alpha.** Проект активно развивается: интерфейс, механики и форматы данных могут меняться. Перед крупным обновлением полезно сохранить папки `Settings` и `Histories`.

## Что умеет NeuroMita

- Общаться с Митами через облачные и локальные LLM.
- Использовать историю, память, RAG и граф знаний, чтобы учитывать прошлые разговоры.
- Связывать ответы с действиями и состоянием персонажа в Unity-сцене.
- Работать с голосовым вводом и озвучкой; локальные модели управляются из AI Hub.
- При необходимости использовать изображения, экран или камеру как дополнительный контекст.
- Хранить API-пресеты, модели, параметры диалога и промпты в настройках приложения.

Часть возможностей требует отдельных загрузок или мощного оборудования. Начните с обычного текстового диалога — для него достаточно подключить один LLM-провайдер.

## Системные требования

- **ОС:** Windows. Другие платформы сейчас не поддерживаются.
- **Интернет:** нужен для первого развёртывания компонентов, обновлений и облачных LLM.
- **LLM:** для облачного варианта требуется ключ выбранного сервиса. Локальная модель в LM Studio ключа не требует, но требует ресурсов компьютера.
- **Голос и локальные компоненты:** могут дополнительно скачать модели и зависимости; для ускорения часто нужна совместимая видеокарта. Конкретные требования зависят от выбранной модели — см. [гайд по локальной озвучке](docs/LocalVoiceInstallation.md).

Не устанавливайте Python, .NET или MelonLoader отдельно: в актуальном релизе встроенный Python и основной runtime поставляются вместе с приложением.

## Скачать и запустить

1. Откройте [страницу релизов](https://github.com/VinerX/NeuroMita/releases) и скачайте актуальный ZIP-архив NeuroMita.
2. Распакуйте архив в отдельную папку, где у вас есть права на запись. Не запускайте приложение прямо из архива.
3. Запустите `Launcher.exe` (или `run.bat`, если launcher не открылся).
4. На первом запуске приложение самостоятельно проверит и развернёт основные Python-зависимости. Не закрывайте окно, пока этот этап не завершится.
5. Откройте приложение. На странице **Главная** установите Unity-часть, если интерфейс предлагает это сделать, затем нажмите **Играть**.

Обновления устанавливаются через **Главную**: отметьте нужные компоненты и нажмите **Обновить**. Обновляйте только из работающего приложения, а не распаковкой нового ZIP поверх открытой папки.

## Первый диалог

1. Откройте **Настройки → API пресеты**.
2. Нажмите **+** или строку «Нажмите, чтобы создать пресет».
3. Выберите шаблон провайдера, вставьте API key и укажите модель.
4. Сохраните пресет и сделайте его активным.
5. Откройте **Настройки → Персонажи**, выберите персонажа и набор промптов.
6. Вернитесь в чат / Sandbox и отправьте первое сообщение.

Самый простой порядок выбора — **OpenRouter → Google AI Studio → Mistral → LM Studio**. Подробные действия и актуальные ссылки: [docs/MODELS.md](docs/MODELS.md).

Если ответ не приходит, сначала проверьте активный пресет, название модели и баланс/лимиты у провайдера, затем откройте [устранение неполадок](docs/TROUBLESHOOTING.md).

## Дополнительные возможности

### Память и RAG

RAG добавляет к запросу релевантные фрагменты истории и воспоминаний. В настройках можно включить поиск, изменить число результатов и порог сходства, а также подключить граф знаний. Подробности: [RAG Guide](docs/RAG_Guide.md).

### Голос и микрофон

В **Настройки → Голос** включается озвучка, а в **Настройки → Микрофон** выбирается устройство и распознавание речи. Локальные модели, ASR и связанные зависимости ставятся через **AI Hub**. Для локальной озвучки используйте [пошаговый гайд](docs/LocalVoiceInstallation.md).

### Локальные модели

NeuroMita умеет работать с сервером LM Studio по локальному OpenAI-совместимому адресу. Это вариант без облачного API-ключа, но скорость и качество зависят от вашей модели и железа. Настройка описана в [гайде по моделям](docs/MODELS.md#lm-studio-локальная-модель).

## Где искать помощь

- Посмотрите [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md): там собраны симптомы, частые HTTP-ошибки и проверка локальных компонентов.
- Откройте раздел **Логи** в приложении или файл `NeuroMitaLogs.log` в папке NeuroMita.
- Если проблема не решена, обратитесь в [Discord](https://discord.gg/Tu5MPFxM4P). Приложите версию NeuroMita, провайдера и модель, шаги воспроизведения, скриншот и релевантный фрагмент лога. **Никогда не публикуйте API keys.**
