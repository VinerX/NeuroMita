# Legacy C# mod

This directory contains the historical C# mod sources that were previously kept at the repository root.

The code is archived for reference and is not the source of truth for the current Unity integration. The maintained Unity-side implementation lives in a separate repository.

The project file retains historical local references to MiSide and MelonLoader assemblies, so building it requires the original external development environment.

Do not add new runtime features here. Changes to the current Unity integration belong in the maintained Unity repository.
