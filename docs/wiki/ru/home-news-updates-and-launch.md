# Главная, новости, обновления и запуск

[Главная вики](./index.md)

## Назначение

Страница `Главная` — рабочая точка входа в приложение. Здесь отображаются состояние установки, обновления, действия запуска и последние новости релиза.

## Что здесь можно сделать

- Установить пакет Unity/игры, если его нет.
- Обновить Python/backend, Unity или оба компонента.
- Запустить установленный исполняемый файл игры.
- Прочитать новости релиза и открыть полную ленту.

## Карточки состояния

Карточки показывают, установлены ли backend и Unity, требуется ли обновление и готов ли запуск. Доступные обновления не выбираются автоматически: значок `NEW` только информирует, а компонент выбирается флажком.

## Основная кнопка

Её значение зависит от состояния: `Install Unity` устанавливает Unity, `Install components (2)` устанавливает оба компонента, `Update` запускает выбранные обновления, `Restart` просит перезапустить приложение, `Play` запускает готовую игру, а `Unity is required to play` сообщает о необходимости Unity. Во время работы Unity появляется `Unity is running — close`.

После нажатия `Play` не закрывайте лаунчер NeuroMita: он поддерживает backend и связь Unity с ИИ. Окно можно свернуть.

Во время загрузки и распаковки кнопку можно использовать для отмены. На этапах проверки и фиксации отмена отключена.

## Восстанавливаемая установка

Компоненты скачиваются с возобновлением, проверяются по размеру и SHA-256 и распаковываются вне рабочей папки. Журнал и манифест позволяют после перезапуска проверить подготовленные файлы и продолжить операцию. При ошибке активации Unity восстанавливается предыдущая папка; незавершённые операции восстанавливаются при следующем запуске.

## Новости

Главная показывает заметки о релизах. Если удалённая лента недоступна, приложение использует локальное состояние. Для полной ленты откройте страницу `Новости`.
