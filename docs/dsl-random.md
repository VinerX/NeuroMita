# Случайные числа в DSL

`random()` возвращает дробное число от 0 включительно до 1 не включительно.
`random(min, max)` возвращает целое число между двумя целыми границами включительно.
Отрицательные границы допустимы. При одинаковых границах результат равен этой границе.

```text
SET LOCAL chance = random()
SET LOCAL variant = random(1, 3)

IF chance < 0.25 THEN
    ADD_CONTEXT_INFO "Предложи неожиданную тему для разговора."
ENDIF

IF variant == 1 THEN
    RETURN "Первый вариант"
ELSEIF variant == 2 THEN
    RETURN "Второй вариант"
ELSE
    RETURN "Третий вариант"
ENDIF
```

Функция доступна в выражениях DSL и Post-DSL, включая условия и форматированные строки.
Каждый выполненный вызов выбирает новое число. Сохраните результат в переменной, если
он должен оставаться одним и тем же в нескольких проверках.

Один аргумент, дробные границы, строки, логические значения и `min > max` вызывают ошибку.
