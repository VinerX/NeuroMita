# НейроМита v0.1 Alpha 
Мод, в котором вам предстоит общаться с Митами управлямыми нейронными сетями. Сделано на Python и C# Unity (Собственный отдельный от основной игры билд).

Внимание, требуются python и c# unity разработчики (среднего уровня и выше), геймдизайнер с навыками непосредственной работы в юнити, аниматоры (с заделом на экспорт в юнити) и моделлеры - пишите в лс дискорд vinerx!
