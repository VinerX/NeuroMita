# Настройка моделей для NeuroMita

> **Проверено: 15 августа 2026 года.** Модели, цены, бесплатные лимиты и доступность по странам меняются часто. Перед выбором всегда сверяйтесь со страницей провайдера и со списком моделей в самом NeuroMita.

## Если не хочется разбираться

Выберите один из этих путей:

1. **OpenRouter** — самый простой старт, когда хочется выбирать из разных семейств моделей через один ключ.
2. **Google AI Studio** — прямой доступ к моделям Gemini, если сервис доступен в вашей стране и для аккаунта.
3. **Mistral** — прямой API Mistral с отдельным ключом.
4. **LM Studio** — полностью локальный вариант: ключ не нужен, но модель должна быть загружена и запущена на вашем ПК.

В приложении все варианты создаются одинаково: **Настройки → API пресеты → +** → выбрать шаблон → указать ключ и модель → сохранить → сделать пресет активным. После этого отправьте короткое сообщение в чат. Успешный ответ — лучшая проверка подключения.

Не вставляйте ключ в сообщение, скриншот, публичный лог или репозиторий. Если ключ показан или утёк, отзовите его у провайдера и создайте новый.

## OpenRouter

OpenRouter объединяет множество моделей и провайдеров под одним OpenAI-совместимым API. В NeuroMita для него уже есть отдельный шаблон, включая настройки маршрутизации.

1. Зарегистрируйтесь на [OpenRouter](https://openrouter.ai/).
2. Создайте ключ на странице [Keys](https://openrouter.ai/keys). Ключ показывается только при создании — сохраните его в надёжном месте.
3. В NeuroMita создайте API-пресет по шаблону **OpenRouter**.
4. Вставьте ключ и выберите модель из [каталога OpenRouter](https://openrouter.ai/models) либо используйте название модели, которое предлагает шаблон.
5. Сохраните пресет и отправьте тестовое сообщение.

У некоторых моделей есть бесплатный доступ, но их список и лимиты меняются. Стоимость, доступность и ограничения показываются в каталоге и аккаунте OpenRouter. Подробнее: [официальный Quickstart](https://openrouter.ai/docs/quickstart) и [FAQ по лимитам](https://openrouter.ai/docs/faq).

## Google AI Studio

Этот путь использует Gemini API напрямую.

1. Откройте [Google AI Studio](https://aistudio.google.com/apikey) и создайте API key.
2. В NeuroMita создайте пресет **Google AI Studio**.
3. Вставьте ключ в поле API key и выберите модель из списка пресета или [официального списка Gemini](https://ai.google.dev/gemini-api/docs/models).
4. Сохраните настройки и проверьте диалогом.

Новые ключи Google AI Studio могут иметь актуальные ограничения и требования к авторизации. Не используйте старые инструкции с правкой системного файла `hosts`: это не часть актуальной настройки NeuroMita. См. [официальную документацию API keys](https://ai.google.dev/gemini-api/docs/api-key).

## Mistral

1. Создайте аккаунт в [Mistral Studio](https://console.mistral.ai/api-keys/).
2. Создайте API key. Провайдер показывает значение ключа один раз.
3. В NeuroMita выберите шаблон **Mistral AI**, вставьте ключ и укажите модель.
4. Актуальные модели проверяйте в [документации Mistral](https://docs.mistral.ai/models/).

Для доступа может потребоваться активировать Studio или способ оплаты — это определяется правилами аккаунта и региона. Актуальная пошаговая справка: [Mistral API Quickstart](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request).

## LM Studio: локальная модель

LM Studio запускает локальную модель и предоставляет OpenAI-совместимый сервер. Текст не уходит в облачный LLM-провайдер, но скорость, память и качество зависят от модели и компьютера.

1. Установите [LM Studio](https://lmstudio.ai/) и скачайте подходящую модель.
2. В LM Studio загрузите модель и включите локальный сервер. По умолчанию шаблон NeuroMita ожидает `http://127.0.0.1:1234/v1/chat/completions`.
3. В NeuroMita создайте пресет **LM Studio**.
4. Укажите модель ровно с тем именем, которое отдаёт локальный сервер. API key для локального сервера обычно не нужен; если LM Studio настроен иначе, заполните поле согласно его настройке.
5. Убедитесь, что LM Studio запущен, затем отправьте сообщение из NeuroMita.

Если возникает ошибка соединения, проверьте запущен ли сервер, совпадает ли порт и не блокирует ли его firewall. Официальные сведения об интерфейсе: [LM Studio OpenAI compatibility](https://lmstudio.ai/docs/developer/openai-compat).

## Другие шаблоны приложения

В текущем интерфейсе также доступны преднастроенные API-пресеты Ai.iO, ProxyAPI, Groq, Together AI, Chutes, KodikRouter и Ollama, а также общий OpenAI-совместимый шаблон. Они предназначены для пользователей, которые уже знают свой endpoint и модель.

Для любого такого провайдера используйте ключ и URL только из его официальной документации. Если сервис вернул HTTP 401, 403 или 429, обратитесь к [устранению неполадок](TROUBLESHOOTING.md#облачная-модель-не-отвечает).

## Как выбирать модель

Не существует одной лучшей модели для всех персонажей и сценариев. Сначала выберите доступный стабильный вариант, затем оцените в нескольких коротких диалогах:

- естественность и соблюдение характера;
- скорость ответа;
- качество русского языка;
- стоимость и лимиты;
- поддержку нужных функций, например изображений или инструментов.

Сохраните удачный вариант отдельным API-пресетом: так можно быстро переключаться, не перезаписывая ключи и параметры.
