# 04. Примеры диалогов

## Проблема

`examplesLong.txt` (Crazy и др.) — поток телеграфных обрывков («Ням, скушала)»,
«Твой ход!») с мета-вставками капсом внутри примеров («НЕ НАДО ВСЕГДА ЗВАТЬ ИГРОКА
В КАРТЫ»). Стиль коротких фраз каноничен, но:

- Примеры даны **голым текстом**, а отвечать модель должна сегментным JSON.
  Few-shot не в формате ответа работает вполсилы и провоцирует форматный дрейф
  на слабых моделях.
- Мета-инструкции вперемешку с примерами сбивают few-shot (модель может принять
  капс-ремарку за часть стиля).

## Предложения

- [ ] **P1.** Переписать примеры как 6–10 мини-сцен «реплика игрока → полный
      JSON-ответ» (с emotions/animations/командами и правильной сегментацией).
      Одна сцена учит сразу четырём вещам: стилю речи, формату ответа, уместному
      использованию тела/эмоций, работе с переменными.
- [ ] **P2.** Вынести мета-инструкции («не всегда зови в карты») из тела примеров
      в правила; примеры оставить чистыми.
- [ ] **P1.** Механизм профилей примеров (full/clean/compact/none) уже реализован
      у Crazy через `Context/examples.script` + `EXAMPLES_PROFILE` — раскатать на
      остальных персонажей (сейчас у большинства только `examplesLong.txt`).
- [ ] **P2.** Для каждого профиля держать версию в формате JSON-ответа (compact —
      3–4 сцены, clean — 6–8, full — больше).

## Затрагиваемые файлы

- `extra/Prompts/Crazy/Default/Context/examplesLong.txt` (+ Clean/Compact варианты)
- `extra/Prompts/Crazy/Default/Context/examples.script` (эталон селектора профиля)
- `extra/Prompts/<Char>/Default/Context/examplesLong.txt` (все остальные)
- `src/controllers/prompt_controller.py::_resolve_examples_profile` (уже есть)

## Заметки

- Профильный механизм (`_resolve_examples_profile`) уже умеет авто-выбор по
  размеру окна модели — сильная фича, её просто нужно наполнить контентом.
