# План улучшений: промпты, контекст, память

Разбор от 2026-07-18 (ветка BetterContext). Собраны все предложения из анализа
промптов персонажей, подачи контекста и систем памяти. Каждый пункт — чекбокс,
чтобы можно было вычеркнуть ненужное перед передачей агентам.

Обозначения приоритета в пунктах:
- **P0** — баг подачи контекста, портит отыгрыш прямо сейчас у всех.
- **P1** — крупный системный выигрыш (качество/токены/масштаб).
- **P2** — улучшение, желательное но не срочное.
- **P3** — идея «на подумать», требует продуктового решения.

## Сквозная тема

Почти во всех файлах повторяется один паттерн-первопричина: **статические
списки-«на-все-случаи» дублируются, расходятся между собой и живут в нескольких
копиях**, вместо того чтобы вычисляться из одного источника правды под текущее
состояние и подаваться рядом с запросом. Он всплывает в: каналах действий (01),
поведенческом состоянии (05), интерпретации памяти (08), стартовых знаниях (09).
Единая линия решения — «один источник → вычисленный срез в volatile-зону».

## Рекомендованный порядок (если делать подряд)

0. 11 (агентная отладка) — не контент, а способ вести все правки ниже с живой
   обратной связью через API. Настраивается один раз, ускоряет остальное.
1. 01 (синхронизация действий) + 03 mojibake/числа — чистые P0-баги.
2. 03 карта дома, 05 DSL-линия поведения — крупный выигрыш, независимы.
3. 09 подключить InitialMemories — почти бесплатно, контент уже написан.
4. 08 куратор памяти + контекстный RAG — под долгую дистанцию.
5. 02 нормализация Cappie/Kind + 04 примеры — качество отыгрыша.
