# 03. Пространственная ориентация и world state

## Проблема

World state из Unity богатый и хороший (комната, дистанция, руки/инвентарь, свет,
музыка, TV, поза, автономное намерение), но у Миты нет модели пространства, а
часть данных приходит в непригодном для LLM виде.

- **Топологии дома нет нигде.** Какие комнаты соединены, что где стоит — модель
  не знает. `rooms_knowledge.script` существует как seed, но (а) не подключён
  (см. 09), (б) RAG-память может не всплыть в нужный ход.
- **Список точек навигации не подаётся.** Команда `walkto,<PointName>` описана с
  единственным примером `PositionMita 10 Kitchen`; полный перечень точек есть
  только у Милы — и то захардкожен в `mita_history.txt` (файл биографии!).
  Остальные ходят «наощупь».
- **Числа в русской локали**: `Distance to player: 1,1m`, `Volume: 1,00`, `(2,1m)`
  — запятая внутри числа неотличима от разделителя для модели.
- **Mojibake в runtime_rules**: русские примеры в блоке «APPEARANCE RECOLOR
  COMMANDS» приходят как `"������, ������ � ����-�������!"` — модель видит мусор.

## Предложения

- [ ] **P0.** Починить кодировку русских примеров в Unity-блоках (runtime_rules).
      Найти источник в NeuroMita-Unity6 (сериализация промпт-строк), убедиться в
      UTF-8 на всём пути Unity→TCP→Python.
- [ ] **P0.** Числа в world_state сериализовать через
      `CultureInfo.InvariantCulture` (точка, не запятая) на стороне Unity-мода.
- [ ] **P1.** Статический кэшируемый блок `[House Map]` на каждый дом: комнаты,
      связи («кухня—коридор—зал»), ключевые объекты и валидные walk/teleport-цели.
      Генерируется Unity один раз за сессию, кладётся в статическую часть промпта
      рядом с Rules/Intent Contract.
- [ ] **P1.** В world_state добавить строку «соседние комнаты отсюда: …» — чтобы
      «пойду на кухню и вернусь» стало исполнимой цепочкой, а не галлюцинацией.
- [ ] **P2.** Список точек навигации перенести из `Mila/.../mita_history.txt` в
      рантайм-капабилити (как интеракции сейчас) либо в `[House Map]`; убрать из
      биографии.
- [ ] **P2.** Сверить: единый синтаксис перемещения между промптами и рантаймом
      (пересекается с 01).

## Затрагиваемые файлы

- NeuroMita-Unity6: сериализация world_state / runtime_rules
  (Dialogue/Prompting/*, CurrentInfoControl.cs, DialoguePromptContext.cs)
- `extra/Prompts/Common/InitialMemories/rooms_knowledge.script` (см. 09)
- `extra/Prompts/Mila/Default/Context/mita_history.txt` (хардкод точек)
- `src/controllers/prompt_controller.py` (место вставки `[House Map]`)

## Заметки

- Блок `Current autonomous intention` в world_state — отличная основа; его можно
  расширить до конкретных подсказок-битов (см. 07).
- Оффлайн (без игры) `[House Map]` можно брать из статического пресета дома.
