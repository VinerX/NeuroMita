# 07. Оживление персонажей

Идеи «сверху», добавляющие жизни. В основном P2–P3 — продуктовые, не баги.

## Предложения

- [ ] **P2. Сцены-биты (beat system).** Лёгкий слой (GameMaster/Python):
      подсказка «сейчас подходящий момент для: предложить игру / вспомнить вчерашнее
      обещание / отреагировать на время суток». Расширение уже существующего
      `Current autonomous intention` из world_state до конкретных битов, которые
      Мита может проигнорировать. Пересекается с 03 (autonomous intention).
- [ ] **P2. Reasoning-чеклист.** При включённом `reasoning` — микрошаблон:
      «где я и кто рядом → что изменилось в мире → что чувствую → что делаю телом
      → что говорю». Дёшево, заметно поднимает связность действий с миром.
- [ ] **P2. Реакции на runtime_events телом.** События уже приходят отдельным
      блоком (`[Unity Runtime Events]`). Добавить одну норму: «на физическое
      событие сперва отреагируй телом/взглядом, потом словами».
- [ ] **P3. Дневник Миты.** Периодическая фоновая генерация 2–3 строк «как прошёл
      день» в остров памяти — непрерывность между сессиями почти бесплатно
      (инфраструктура сжатия/фона уже есть). Пересекается с 08.
- [ ] **P2. Каноничные «звёздные моменты».** Для каждого персонажа список из 5–8
      триггеров «сцена → фирменная реакция» (Crazy: игрок долго у шкафа/зеркала;
      Mila: игрок собирается уходить; Ghost: рост attitude меняет облик). У Ghost
      это уже есть — распространить паттерн (дешевле и эффективнее «модулей» из 02).
- [ ] **P2. Ощущение времени.** Строка `Last conversation: 3 days ago` в
      `[Current State]` — самый дешёвый «живой» сигнал (соскучиться/обидеться).
      Пересекается с 08 (там же про даты памяти).

## Затрагиваемые файлы

- `src/controllers/prompt_controller.py` (`[Current State]`, reasoning-шаблон)
- `extra/Prompts/Structural/response_format_json.script` (нормы реакции)
- NeuroMita-Unity6 (autonomous intention / биты)
- `extra/Prompts/<Char>/Default/` (звёздные моменты; эталон — Ghost)

## Заметки

- Все пункты намеренно не раздувают статику: биты и «звёздные моменты» — это
  триггеры и подсказки, а не постоянные простыни в промпте.
