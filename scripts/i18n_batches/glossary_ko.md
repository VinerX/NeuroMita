# Glossary — Korean (ko)

Target: Korean. Use standard software-UI conventions. Use 합쇼체 (formal polite, ~합니다/습니다) for user-facing verbs, noun form for labels.
Use hangul; loanwords in standard Korean form.

- Settings → 설정 ; Save → 저장 ; Delete → 삭제 ; Refresh → 새로고침 ; Reset → 초기화 ; Cancel → 취소 ; Confirm → 확인 ; Close → 닫기

- Session → 세션 ; State → 상태 ; Status → 상태 ; History → 기록 ; Clear chat → 채팅 지우기 ; Chat → 채팅
