# Glossary — Ukrainian (uk)

Target: Ukrainian. Standard software-UI conventions. Use proper Ukrainian (not russianisms): "застосунок", "налаштування", "вилучити/видалити".

- Settings → Налаштування ; Save → Зберегти ; Delete → Видалити ; Refresh → Оновити ; Reset → Скинути ; Cancel → Скасувати ; Confirm → Підтвердити ; Close → Закрити
- Voice → Озвучення ; Microphone → Мікрофон ; Capture → Захоплення ; Screen capture → Захоплення екрана ; Camera capture → Захоплення з камери
- Session → Сесія ; State → Стан ; Status → Статус ; History → Історія ; Clear chat → Очистити чат ; Chat → Чат
- Character → Персонаж ; Prompt set → Набір промптів ; Model → Модель ; Memory → Пам'ять
- Quick actions → Швидкі дії ; Active session → Активна сесія ; Full settings → Повні налаштування
- Character settings → Налаштування персонажа ; Reset character → Скинути персонажа ; View last request → Переглянути останній запит
- Language → Мова ; Update → Оновлення ; Download → Завантажити ; Install → Встановити ; Enable → Увімкнути ; Disable → Вимкнути
- key (API key) → ключ ; chunk → фрагмент ; embedding → embedding ; token → токен ; backup → резерв
- Home → Головна ; Releases → Релізи ; Logs → Логи ; Guide → Посібник ; Sandbox → Пісочниця ; Privacy → Приватність
- "Conversation with " → "Розмова з " (keep trailing space)
