# Glossary — Greek (el)

Target: Modern Greek (Ελληνικά). Standard software-UI conventions.

- Settings → Ρυθμίσεις ; Save → Αποθήκευση ; Delete → Διαγραφή ; Refresh → Ανανέωση ; Reset → Επαναφορά ; Cancel → Ακύρωση ; Confirm → Επιβεβαίωση ; Close → Κλείσιμο
- Voice → Φωνή ; Microphone → Μικρόφωνο ; Capture → Λήψη ; Screen capture → Λήψη οθόνης ; Camera capture → Λήψη κάμερας
- Session → Συνεδρία ; State → Κατάσταση ; Status → Κατάσταση ; History → Ιστορικό ; Clear chat → Εκκαθάριση συνομιλίας ; Chat → Συνομιλία
- Character → Χαρακτήρας ; Prompt set → Σύνολο προτροπών ; Model → Μοντέλο ; Memory → Μνήμη
- Quick actions → Γρήγορες ενέργειες ; Active session → Ενεργή συνεδρία ; Full settings → Πλήρεις ρυθμίσεις
- Character settings → Ρυθμίσεις χαρακτήρα ; Reset character → Επαναφορά χαρακτήρα ; View last request → Προβολή τελευταίου αιτήματος
- Language → Γλώσσα ; Update → Ενημέρωση ; Download → Λήψη ; Install → Εγκατάσταση ; Enable → Ενεργοποίηση ; Disable → Απενεργοποίηση
- key (API key) → κλειδί ; chunk → τμήμα ; embedding → embedding ; token → token ; backup → εφεδρεία
- Home → Αρχική ; Releases → Εκδόσεις ; Logs → Αρχεία καταγραφής ; Guide → Οδηγός ; Sandbox → Sandbox ; Privacy → Απόρρητο
- "Conversation with " → "Συνομιλία με " (keep trailing space)
