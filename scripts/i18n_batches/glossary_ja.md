# Glossary — Japanese (ja)

Target: Japanese. Use standard software-UI conventions. Use です/ます for user-facing text, dictionary form for labels.
Use katakana for loanwords, Chinese characters where natural for Japanese.

- Session → セッション ; State → 状態 ; Status → ステータス ; History → 履歴 ; Clear chat → チャットをクリア ; Chat → チャット
