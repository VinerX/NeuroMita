# Glossary — German (de)

Target: German. Use standard German software-UI conventions (formal "Sie" where a sentence addresses the user). Capitalize nouns.

- Settings → Einstellungen ; Save → Speichern ; Delete → Löschen ; Refresh → Aktualisieren ; Reset → Zurücksetzen ; Cancel → Abbrechen ; Confirm → Bestätigen ; Close → Schließen
- Voice → Stimme ; Microphone → Mikrofon ; Capture → Aufnahme ; Screen capture → Bildschirmaufnahme ; Camera capture → Kameraaufnahme
- Session → Sitzung ; State → Zustand ; Status → Status ; History → Verlauf ; Clear chat → Chat leeren ; Chat → Chat
- Character → Charakter ; Prompt set → Prompt-Satz ; Model → Modell ; Memory → Speicher
- Quick actions → Schnellaktionen ; Active session → Aktive Sitzung ; Full settings → Alle Einstellungen
- Character settings → Charaktereinstellungen ; Reset character → Charakter zurücksetzen ; View last request → Letzte Anfrage anzeigen
- Language → Sprache ; Update → Update ; Download → Herunterladen ; Install → Installieren ; Enable → Aktivieren ; Disable → Deaktivieren
- key (API key) → Schlüssel ; chunk → Segment ; embedding → Embedding ; token → Token ; backup → Reserve
- Home → Start ; Releases → Releases ; Logs → Protokolle ; Guide → Anleitung ; Sandbox → Sandbox ; Privacy → Datenschutz
- "Conversation with " → "Unterhaltung mit " (keep trailing space)
